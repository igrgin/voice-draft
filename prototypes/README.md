# Early workflow prototypes

These experiments informed the first implementation of Voice Draft. They are
kept as design history and are separate from the runnable app in `backend/` and
`frontend/`. Their mock transitions and setup notes reflect the original design.

- [Backend processing pipeline](issue-7-backend-pipeline/README.md): a terminal
  prototype for upload, transcription, cleanup and recovery states.
- [Frontend workflow](issue-8-frontend-workflow/README.md): three early recording
  and review layouts built with mocked data.
